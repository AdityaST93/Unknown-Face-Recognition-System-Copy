The project downloads model weights at runtime. They are stored in `models/` and are not committed to Git.

| Model | Source | License / notes |
|---|---|---|
| YuNet `face_detection_yunet_2023mar.onnx` | [OpenCV Zoo model card](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) | The model directory identifies its license as MIT. |
| SFace `face_recognition_sface_2021dec.onnx` | [OpenCV Zoo model card](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface) | The model directory identifies its license as Apache-2.0. |
